# 2026_07_25_godot_jam_with_vincent

> A small game jam with Vincent focused on Llama.cpp integration.

The goal of this project is to create a game that communicates with a local **Llama.cpp** server.

This project depends on the **Learn With Sensors** add-on, which introduces significant modifications to the project. Because of this dependency, the project may be fragile and can break if the add-on changes.
